# CodeAlpha Calculator — ColorPop

A colorful, responsive calculator built with HTML, CSS, and vanilla JavaScript for the CodeAlpha Frontend Development task.

## Features

- Addition, subtraction, multiplication, and division
- Live expression display and result calculation
- Clear all, delete last digit, percentage, sign toggle, and decimals
- Keyboard support: digits, `+`, `-`, `*`, `/`, `Enter`, `Backspace`, `Escape`, `%`
- Responsive layout, gradient styling, hover feedback, and subtle animations
- Accessible labels and reduced-motion support
- No framework or build step required

## Run locally

Open `index.html` in your browser.

## Deploy with GitHub Pages

1. Create a **public** repository named `CodeAlpha_Calculator`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root (not inside an extra nested folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save if the button is enabled.
6. Wait for deployment, then open `https://YOUR-USERNAME.github.io/CodeAlpha_Calculator/`.

If you use GitHub Actions for Pages instead, choose the **Static HTML** Pages workflow or use a Pages deployment workflow configured for a static site.
